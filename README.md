# Knowledge Bases

Public, evergreen reference notes by [Ashar Farooq](https://ashar.vercel.app). Each folder is one knowledge base on one topic, written to stay accurate for years rather than track things that change week to week.

## How it's organized

- One folder per knowledge base, each with a `README.md` index.
- One Markdown file per entry, named in lowercase with hyphens (`dns.md`, `oauth.md`).
- Each entry starts with a short front-matter block (`title`, `tags`, `updated`).
- Entries link to related entries with relative links, so the repo reads well on GitHub, in Obsidian, or as a static site.
- New entries start from [`_template.md`](_template.md).

## What doesn't go here

Nothing personal: no private data, account details, or anything that changes often (prices, schedules, event listings).
